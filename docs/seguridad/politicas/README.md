# Políticas de TechCare

| Política | Tema |
|---|---|
| [Control de acceso](politica_acceso.md) | Mínimo privilegio, roles por grupo y área, accesos privilegiados, terceros e IA |
| [Contraseñas y autenticación](politica_contrasenas.md) | Requisitos, bloqueos, recuperación, 2FA, sesiones, credenciales técnicas |
| [Información sensible](politica_informacion_sensible.md) | Clasificación, manejo de datos de menores y médicos, IA y proveedores, retención |
| [Gestión de cambios](politica_cambios.md) | Tipos de cambio, flujo con ramas, pruebas, aprobación, despliegue y reversión |
| [Desarrollo de software](politica_desarrollo_software.md) | Ciclo de vida, codificación segura, pruebas, dependencias, uso de IA en el desarrollo |

**Revisión de las políticas:**
1. Revisión por TI y por los dueños de la información.
2. Ajustes.
3. Aprobación de la Dirección, registrando fecha y versión.
4. Comunicación al personal, ver el [plan de capacitación](../09_plan_capacitacion.md).
5. Revisión anual.
