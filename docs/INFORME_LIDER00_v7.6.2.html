Módulo de Red: las cuatro funciones entregadas

Listo

Acceso por grupos

El módulo deja de ser exclusivo del superadministrador. Dos grupos nuevos: red (ver y exportar, pensado para soporte/TI) y red_admin (administrar y aprobar migraciones, para el responsable). Las 33 pantallas que modifican datos quedan bloqueadas para quien solo tiene lectura; probado con usuarios de cada perfil.

Listo

Monitoreo continuo

Cada 15 minutos el servidor hace ping a todos los equipos con IP y guarda estado y latencia. Avisa por la campana y correo solo cuando un equipo cae o vuelve, para no generar ruido. Durante la puesta en marcha se detectó y corrigió un error de configuración del cron.

Listo

Migración real de VLAN

El planificador ya ejecuta: se eligen los equipos, se exige un motivo y una confirmación explícita, y solo puede hacerlo quien tiene el permiso Aprobar migraciones. Se procesa equipo por equipo: libera la IP anterior, asigna la primera libre del destino y actualiza el registro; si uno falla, se revierte solo ese. Todo queda en auditoría. Probado de punta a punta.

Listo

Exportación y API

La topología se exporta ahora en SVG y PDF además de PNG. Nueva API de solo lectura en /red/api/v1/ (VLANs, IPs, dispositivos, switches, enlaces, ubicaciones, gabinetes) con búsqueda, filtros y acceso por sesión o por token, para integraciones con monitoreo u otros sistemas.
